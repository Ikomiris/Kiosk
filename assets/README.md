# Dossier Assets - Images

Ce dossier contient les images utilisées pour les cartes de service de l'interface kiosk.

## Images requises

Placez les images suivantes dans ce dossier :

### 1. calendar.jpg
- **Service** : Prendre rendez-vous
- **Description** : Image d'un calendrier avec une date encerclée
- **Dimensions recommandées** : 800x800px minimum
- **Format** : JPG, PNG

### 2. gift.jpg
- **Service** : Acheter une carte cadeau
- **Description** : Image d'un nœud cadeau doré/orange
- **Dimensions recommandées** : 800x800px minimum
- **Format** : JPG, PNG

### 3. account.jpg
- **Service** : Créer un compte
- **Description** : Icône de personne/utilisateur avec symbole +
- **Dimensions recommandées** : 800x800px minimum
- **Format** : JPG, PNG

### 4. iris.jpg
- **Service** : Consulter le catalogue
- **Description** : Image d'un iris (œil) coloré
- **Dimensions recommandées** : 800x800px minimum
- **Format** : JPG, PNG

### 5. faq.jpg
- **Service** : Consulter la FAQ
- **Description** : Blocs avec lettres F, A, Q
- **Dimensions recommandées** : 800x800px minimum
- **Format** : JPG, PNG

## Spécifications techniques

- **Ratio** : 1:1 (carré) recommandé
- **Poids** : < 500KB par image pour des performances optimales
- **Qualité** : Moyenne à haute (les images seront affichées avec une opacité de 80%)
- **Formats acceptés** : JPG, PNG, WebP

## Notes

- Les images seront automatiquement redimensionnées pour s'adapter aux cartes
- Une opacité de 80% est appliquée pour permettre une meilleure lisibilité du texte
- Le texte jaune/doré sera superposé sur ces images
- Privilégiez des images avec des zones sombres pour une meilleure lisibilité du texte

## Extraction depuis la maquette

Les images peuvent être extraites de la maquette `visuelKiosk.jpg` située à la racine du projet.
